BubbleTea Bliss Cafe - Project Proposal

 Proposal – BubbleTea Bliss Cafe
1. Introduction
We propose to design and develop a visually engaging, interactive website for BubbleTea Bliss Cafe, a fictional bubble tea shop. The website will feature a vibrant and modern design, showcasing a detailed menu, creative barista profiles, and an online ordering simulation. The aim is to create an immersive user experience that combines aesthetics with functionality, reflecting the lively and playful nature of bubble tea culture.
2. Unique Project Name
BubbleTea Bliss Cafe
3. Reason – Why Bubble Tea Cafe?
We chose a bubble tea cafe as our project theme because it offers the perfect blend of creativity, visual appeal, and functionality for a web design project. Bubble tea is a trendy and globally popular drink that attracts a young and dynamic audience, making it ideal for vibrant color schemes, high-quality imagery, and engaging content.
A bubble tea cafe concept allows us to:
•	Showcase Visual Design Skills – Using bright, refreshing colors and appealing drink images to create an inviting atmosphere.
•	Demonstrate Structured Navigation – Organizing multiple menu categories (Drinks, Toppings, Combos) into user-friendly pages.
•	Incorporate Interactive Elements – Simulating online ordering, highlighting barista profiles, and integrating contact forms.
•	Create a Relatable Theme – Food and beverage topics resonate with a wide audience, ensuring a fun and accessible user experience.
In short, a bubble tea cafe offers a rich design space for demonstrating both creative design and technical web development skills while appealing to the senses of our target audience.
4. Learning Reflection
Through this project, we aim to demonstrate and apply:
•	HTML & CSS – For structured content, responsive layouts, and creative styling.
•	JavaScript – For interactive features like order simulations and dynamic menus.
•	Usability Principles – Ensuring accessibility, intuitive navigation, and a smooth user experience.
•	Content Organization – Presenting multi-level menus and clear page structures.
•	Branding & Design Consistency – Maintaining a cohesive look through consistent typography, color palettes, and imagery.
5. Visual Plan
The website will include the following pages:
•	Home – Hero section featuring signature drinks and promotions.
•	About Us – Team introduction with barista “portfolios.”
•	Menu – Split into three subpages: Drinks, Toppings, and Combos.
•	Contact – Location details and an order simulation form.
Proposed Color Palette:
•	Electric Blue – For bold accents and navigation highlights.
•	Vibrant Coral – To convey warmth and energy.
•	Emerald Green – To represent freshness and natural ingredients.
Guide for Others
This project has been designed with simplicity in mind so that anyone can set it up and continue developing it further.
Setup Instructions:
1.	Clone or download the repository from GitHub.
2.	Open the project folder in a code editor such as VS Code.
3.	Run the project by opening index.html in any modern web browser.
Tools and Technologies Used:
•	HTML, CSS, JavaScript – for building and styling the website.
•	Figma – for the design prototype and layout planning.
•	GitHub – for version control and collaboration.
How to Continue/Contribute:
•	Expand the website by adding new pages (e.g., Online Ordering, Blog, Rewards Program).
•	Enhance responsiveness for different devices and screen sizes.
•	Improve interactivity by adding animations, forms, or dynamic content using JavaScript.
•	Customize branding easily by editing CSS styles, fonts, and images.
This guide ensures that future contributors or developers can quickly set up, understand, and build upon the Bubble Tea Bliss project.
